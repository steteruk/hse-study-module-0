# Магистратура «Искусственный интеллект» — Нулевой модуль

Данный репозиторий создан для выполнения и хранения практических заданий в рамках нулевого модуля магистратуры по направлению **«Искусственный интеллект»**. 

## Проект: Автоматизированный разведочный анализ данных (EDA) датасета Titanic

В рамках первого домашнего задания был исследован знаменитый датасет **Titanic (Пассажиры Титаника)**. Цель работы — провести комплексный первичный анализ данных (Exploratory Data Analysis), выявить скрытые закономерности, оценить качество данных и сформировать аналитический отчет.

### Структура репозитория

*   `Homework1/` — папка с материалами первого домашнего задания.
    *   `collect-report.ipynb` — Jupyter Notebook с кодом для автоматической загрузки данных по ссылке и генерации EDA-отчета.
    *   `titanic_report.html` — интерактивный HTML-отчет с визуализациями, корреляционными матрицами и статистикой по пассажирам.
    *   `titanic-quality-report.docx` — текстовый документ с самостоятельным описанием признаков и детальным разбором проблем в данных (пропуски, дубликаты, аномалии).

### Используемые технологии и библиотеки

*   **Python 3.x** — язык разработки.
*   **Pandas** — чтение данных напрямую из репозитория по URL.
*   **ydata-profiling** — инструмент для автоматического создания интерактивного профиля данных.
